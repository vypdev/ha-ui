# Home Assistant UI

Shared presentation components for Home Assistant applications, including Gateway and Domus.

The proposed library has one Lit component implementation, direct Lit/HTML consumption and real
React, Vue, Angular and Svelte adapters. Each app owns its data, permissions, routes and workflows.
One Storybook will document the same components and their accessibility/theme/localization states.

The repository is configured; product implementation and publication have not started.
Start with the [component-library guide](docs/component-library.md),
[primary Draft](specs/shared-ui-foundation.md), [specification standard](specs/README.md)
and [capability catalog](specs/CATALOG.md). The [implementation issue](https://github.com/vypdev/ha-ui/issues/7)
retains the full scope and pending native specification gate.
